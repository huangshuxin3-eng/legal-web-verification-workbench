# 非诉网核 · 网页核查助手 External Beta 安装说明

## A. 使用前准备

请准备：

- Google Chrome 118 或更高版本；
- 一个“非诉网核工作台”账号；
- 可以访问公网工作台：<https://legal-web-verification-workbench.vercel.app>。

网页端与插件端使用同一个邮箱账号。当前两边的登录状态相互独立，因此首次使用插件时，需要在插件中再登录一次。

## B. 安装插件

1. 下载收到的 Beta ZIP 文件。
2. 将 ZIP 解压到一个固定文件夹。
3. 在 Chrome 地址栏输入 `chrome://extensions` 并打开。
4. 打开页面右上角的“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 选择刚才解压得到的文件夹。正确的文件夹中可以直接看到 `manifest.json`。
7. 扩展列表出现“非诉网核 · 网页核查助手”，即表示安装成功。

不要直接选择 ZIP 文件，必须先解压。安装后不要删除或移动解压后的文件夹，否则 Chrome 可能无法继续加载插件。

## C. 第一次使用

1. 打开公网工作台并登录；没有账号时先注册，并按邮箱提示完成确认。
2. 创建项目。
3. 在项目中创建核查任务。
4. 打开“非诉网核 · 网页核查助手”。
5. 使用与网页端相同的邮箱账号登录插件。
6. 在插件中选择项目与核查任务。
7. 开始核查。
8. 目标网站要求安全验证时，请按页面提示由本人完成，再按插件提示继续。
9. 留痕完成后，返回工作台查看核查结果、AI 分析和报告。

## D. 正常现象

- Chrome 可能提示正在使用开发者模式扩展，这是通过“加载已解压的扩展程序”安装 Beta 版时的正常提示。
- 生成完整 PDF 留痕时，Chrome 可能短暂显示“扩展正在调试此浏览器”或“正在调试此页面”之类的提示。该提示来自当前 PDF 留痕流程，留痕结束后会解除。

## E. 常见问题

### 1. 插件看不到项目

- 确认插件登录邮箱和网页端登录邮箱一致；
- 确认网页端已经创建项目；
- 尝试退出插件账号后重新登录。

### 2. 插件登录失败

- 确认邮箱已经完成验证；
- 确认输入的密码正确；
- 确认当前网络可以访问 Supabase 服务。

### 3. Chrome 提示“找不到 manifest”

通常是选择了错误的文件夹。请重新选择其中直接包含 `manifest.json` 的解压目录，不要选择 ZIP 文件或它的上一级文件夹。

### 4. 自动核查要求人工验证

这是目标网站的安全验证。请本人完成验证，再按插件提示继续操作。

### 5. PDF 留痕时出现 debugger 提示

这是当前完整 PDF 留痕实现的正常现象，留痕结束后会解除。

## F. Beta 说明

当前版本为 External Beta，仅用于真实流程测试。遇到问题时，请记录：

- 发生问题前的操作步骤；

无需打开 DevTools，也不要提供 access token、refresh token、密码或其他账号凭证。
