# LegalTrace 网页核查助手 · 安装说明

本文只说明如何安装 LegalTrace 的 Chrome Extension（网页核查助手），不包含完整的产品操作流程。

完整产品使用流程请见：[LegalTrace 使用手册](./USER_GUIDE.md)。

## A. 使用前准备

请准备：

- Google Chrome 118 或更高版本；
- 一个 LegalTrace 账号；
- 可以访问公网工作台：<https://legal-web-verification-workbench.vercel.app>。

网页端与插件端使用同一个邮箱账号。当前两边的登录状态相互独立，因此首次使用插件时，需要在插件中再登录一次。

## B. 安装插件

1. 下载收到的 Beta ZIP 文件。
2. 将 ZIP 解压到一个固定文件夹。
3. 在 Chrome 地址栏输入 `chrome://extensions` 并打开。
4. 打开页面右上角的「开发者模式」。
5. 点击「加载已解压的扩展程序」。
6. 选择刚才解压得到的文件夹。正确的文件夹中可以直接看到 `manifest.json`。
7. 扩展列表出现「网页核查助手」，即表示安装成功。

不要直接选择 ZIP 文件，必须先解压。安装后不要删除或移动解压后的文件夹，否则 Chrome 可能无法继续加载插件。

## C. 安装后第一次打开

1. 确认已经在公网工作台注册账号，并完成邮箱确认。
2. 打开「网页核查助手」侧边栏。
3. 使用与 Web 工作台相同的邮箱账号登录插件。
4. 如果插件可以读取当前账号下的项目，即表示安装和登录成功。

Web 与 Extension 使用同一个邮箱账号，但当前登录状态相互独立。因此，即使已经登录 Web 工作台，第一次打开插件时仍需再次登录。

创建项目、创建任务、开始核查、查看证据和生成报告等步骤，请按照 [LegalTrace 使用手册](./USER_GUIDE.md) 操作。

## D. 正常现象

- Chrome 可能提示正在使用开发者模式扩展，这是通过「加载已解压的扩展程序」安装 Beta 版时的正常提示。
- 生成完整 PDF 留痕时，Chrome 可能短暂显示「扩展正在调试此浏览器」或「正在调试此页面」之类的提示。该提示来自当前 PDF 留痕流程，留痕结束后会解除。

## E. 常见问题

### 1. 插件看不到项目

- 确认插件登录邮箱和网页端登录邮箱一致；
- 确认网页端已经创建项目；
- 尝试退出插件账号后重新登录。

### 2. 插件登录失败

- 确认邮箱已经完成验证；
- 确认输入的密码正确；
- 确认当前网络正常，并尝试重新登录。

### 3. Chrome 提示「找不到 manifest」

通常是选择了错误的文件夹。请重新选择其中直接包含 `manifest.json` 的解压目录，不要选择 ZIP 文件或它的上一级文件夹。

### 4. 自动核查要求人工验证

这是目标网站的安全验证。请本人完成验证，再按插件提示继续操作。

### 5. PDF 留痕时为什么出现「正在调试此页面」的提示

Chrome 在生成完整 PDF 留痕时可能短暂显示「正在调试此页面」的提示，这是正常现象，留痕结束后会解除。
