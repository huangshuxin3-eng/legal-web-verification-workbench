# LegalTrace 使用手册

本手册面向第一次使用 LegalTrace 的律师、法务、实习生及其他核查人员。

## 产品使用流程

```text
注册账号
→ 创建项目
→ 创建核查任务
→ 安装网页核查助手
→ 开始核查
→ 查看证据与结果
→ 生成 AI 辅助分析
→ 人工确认
→ 生成报告
```

完整核查流程需要桌面版 Google Chrome 和「网页核查助手」扩展。手机浏览器不能完成需要浏览器扩展程序的自动核查流程。

公网工作台：<https://legal-web-verification-workbench.vercel.app>

## 1. 注册与登录

账号用于保存和隔离你自己的项目、核查任务与证据。

首次打开公网工作台时，你会先看到产品首页，点击页面上的入口按钮后进入登录页。登录页默认显示登录表单：

1. 在登录页填写邮箱和密码，点击登录。
2. 新用户请点击表单下方的「注册」切换到注册表单，填写邮箱、密码和确认密码。
3. 如果页面提示前往邮箱确认，请打开注册邮件并完成确认。
4. 返回登录页，使用注册邮箱和密码登录。

如果注册后直接进入工作台，说明当前账号已经取得登录状态，不需要再次登录。本版本暂未提供「忘记密码」入口。

## 2. 创建项目

「项目」用于组织同一个尽调事项下的核查工作。一个项目可以包含多个核查对象和多项核查任务。

1. 登录后，在工作台首页点击「新建项目」。
2. 填写项目名称；项目编号可以不填。
3. 保存后进入项目工作台。

工作台左侧是项目导航，列出你名下的全部项目，可以直接点击切换。

项目名称用于描述整个事项，不要求等于某一次具体查询对象。例如，一个项目可以命名为「某交易相对方公开信息核查」，项目内再分别创建多个公司的核查任务。

## 3. 创建核查任务

一个核查任务表示「对谁、查什么、从哪个数据来源查询」。

例如：

- 核查对象：XX有限公司
- 核查事项：执行
- 数据来源：中国执行信息公开网

在项目工作台顶部可以：

- 点击「新建核查任务」新增一项任务；
- 点击「批量创建」进入批量创建页，一次输入多个核查对象并选择核查范围；
- 点击已有任务行，查看或编辑任务信息、查询记录和证据留痕。

批量创建页按三步进行：先粘贴核查对象（每行一个，重复名称会自动去重），再勾选核查事项与数据来源，最后在预览列表里确认后创建。

创建前请检查主体名称。网页核查助手会使用任务中保存的核查对象进行查询。

## 4. 安装网页核查助手

网页核查助手负责在目标网站执行查询、翻页、打开详情并生成 PDF 证据。

插件需要通过 Chrome 的「加载已解压的扩展程序」安装。完整步骤请参阅：[网页核查助手安装说明](./EXTERNAL_BETA_INSTALL.md)。

## 5. 开始自动核查

1. 使用桌面版 Chrome 打开「网页核查助手」侧边栏。
2. 使用与 Web 工作台相同的邮箱和密码登录。
3. 选择项目和核查任务。
4. 点击开始核查，并按插件提示操作。
5. 目标网站要求安全验证时，由用户本人在网页中完成验证。
6. 验证完成后，按插件提示继续核查。
7. 核查结束后返回 Web 工作台，查看查询记录和证据留痕。

Web 工作台与插件使用同一个邮箱账号，但当前登录状态相互独立。第一次使用插件时，即使网页端已经登录，也需要在插件中再登录一次。

## 6. 核查中断怎么办

网络异常、浏览器关闭或网站验证中断，都可能使一次核查暂停。

重新打开 Chrome 和网页核查助手后，回到原核查任务并按插件提示继续。系统会保留已经完成的进度；重新进入任务时，已经成功生成的证据不会自动重复生成。

如果页面内容、结果数量或分页情况已经发生变化，插件可能暂停继续执行。此时不要反复点击开始，先记录提示和截图，再决定是否重新发起核查。

## 7. 查看证据和结构化结果

PDF 证据是目标网站在核查时显示内容的留存文件，用于后续复核。每次真实查询会形成查询记录，PDF 证据保存在对应的查询记录下，可以在工作台中预览或下载。

系统会从符合报告条件的执行详情证据中整理案号、法院、日期、金额、公示类型等信息。报告中的证据索引会列出对应证据文件，便于从整理后的记录回到原始页面留痕。

如果公开页面没有公示某个字段，系统会保持该字段为空。空白不等于「0」「无」或「不存在」。

## 8. AI 辅助分析

在项目工作台点击顶部工具栏的「生成报告」，在弹出的「生成尽调报告」窗口中，找到「AI 辅助分析」区域，点击「生成 AI 分析」，可以得到：

- 核查结果概览
- 重点关注事项
- 重点记录
- 建议进一步核实事项

AI 分析基于已经整理的核查结果，不直接决定案号、金额、日期、数量等基础事实。生成内容属于辅助分析草稿，不构成正式法律意见。

如果窗口底部提示项目暂无可用于生成报告的执行详情留痕，请先完成对应核查任务。

## 9. 编辑与人工确认

AI 内容不会自动进入最终报告。生成草稿后，请按以下顺序操作：

1. 查看四部分内容；
2. 必要时直接修改文本；
3. 点击「保存修改」；
4. 检查无误后点击确认按钮将分析标记为已确认。

只有已确认的 AI 内容才会进入报告。修改已经确认的分析后，需要先保存，再重新确认。未保存的修改不会进入报告。

窗口底部会显示当前状态（如「未生成」「已保存 · 待确认」「已确认」「有未保存修改」），可据此判断分析是否可以随报告输出。

## 10. 为什么有时需要重新生成 AI 分析

AI 分析对应生成时的核查结果。如果确认分析以后又重新进行了核查，并且底层核查结果发生变化，之前的分析不能继续用于新报告。

遇到提示时，请按以下顺序处理：

1. 重新生成 AI 分析；
2. 检查新草稿；
3. 必要时修改并保存；
4. 再次确认；
5. 重新生成报告。

## 11. 生成报告和导出成果

### 生成 DOCX 报告

1. 在项目工作台顶部工具栏点击「生成报告」。
2. 如需让 AI 分析进入报告，先在「生成尽调报告」窗口内完成编辑、保存和确认。
3. 点击窗口底部的「生成报告」。
4. 浏览器开始下载 DOCX 文件。

报告主要包括核查说明、执行及失信公开信息明细、律师提示和证据索引。已经人工确认且仍与当前核查结果一致的 AI 分析会作为单独章节进入报告；没有确认 AI 分析时，仍可生成不含该章节的报告。

如果项目尚未产生可用的执行详情留痕，或 AI 分析存在未保存修改，生成按钮会被禁用，并在按钮旁显示原因。

### 导出项目成果

1. 在项目工作台右上角点击「项目设置」。
2. 在下拉菜单中点击「导出成果」。
3. 在弹出的「导出成果」窗口中确认项目的核查对象、任务和证据数量。
4. 点击「下载成果包」。

下载的 ZIP 成果包包括 Excel 核查清单，以及按核查对象和事项整理的 PDF 证据文件。没有证据留痕的任务不会进入成果包。

## 12. 常见问题

### 1. 插件看不到项目

- 确认插件与 Web 工作台登录的是同一个邮箱；
- 确认项目已经在 Web 工作台中创建成功；
- 退出插件账号后重新登录；
- 检查当前网络是否可以访问公网工作台和登录服务。

### 2. 插件登录失败

- 确认邮箱已经完成验证；
- 重新检查邮箱和密码；
- 确认当前网络可以访问登录服务；
- Web 与插件登录状态独立，网页端已登录不代表插件端已经登录。

### 3. Chrome 提示「找不到 manifest」

通常是选择了错误的目录。请先解压 Beta ZIP，再选择其中直接包含 `manifest.json` 的文件夹。不要选择 ZIP 文件或它的上一级目录。

### 4. 为什么需要人工安全验证

安全验证由目标网站提供，需要用户本人完成。网页核查助手不会自动绕过验证。完成后请按插件提示继续。

### 5. PDF 留痕时为什么出现 Chrome 调试提示

生成完整 PDF 时，Chrome 可能短暂提示扩展正在调试浏览器或当前页面。这是当前 PDF 留痕方式的正常现象，留痕结束后会解除。

### 6. 核查中断以后怎么办

重新打开 Chrome 和插件，回到原任务并按提示继续。系统会保留已完成证据；如果网站结果已经变化，插件可能暂停，并要求用户重新判断是否发起核查。

### 7. 为什么某些字段为空

公开页面未公示相应字段时，系统会保持为空。空白不表示数值为 0，也不表示相关情况不存在。

### 8. 为什么 AI 分析要求重新生成

说明底层核查结果在原分析确认后发生了变化。请重新生成、检查并确认分析，再生成报告。

### 9. AI 服务暂时不可用怎么办

稍后重试「生成 AI 分析」。生成失败不会删除此前已经保存的草稿。

- 如果项目尚未确认 AI 分析，可以生成不含 AI 分析章节的报告；
- 如果系统提示已确认的 AI 分析基于旧版核查结果，则需要重新生成并确认 AI 分析后，才能继续生成报告。

### 10. 报告无法生成时应先检查什么

- 项目中是否已经完成执行信息核查并生成证据；
- AI 内容是否有尚未保存的修改；
- 页面是否提示 AI 分析需要重新生成；
- 页面是否提示证据读取或解析失败。

请不要反复点击生成，也不要自行修改证据文件。如果仍无法生成，请保留页面完整提示和截图，并反馈给 Beta 测试联系人。

## 13. Beta 问题反馈

遇到无法自行解决的问题，请联系邀请你参与本次 Beta 测试的联系人。

反馈问题时，请提供：

- 出问题前做了什么；
- Web 页面或插件显示的完整提示；
- 能说明问题的截图；
- 使用的 Chrome 版本（与插件或网页操作相关时）。

请不要提供：

- 密码
- access token
- refresh token
- API key
- 其他账号凭证

如截图中包含客户名称、案号或其他敏感信息，请先完成脱敏。
